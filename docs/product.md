# 产品说明 — 《星火》

## 产品定位与目标用户

**产品定位：** 以抗日战争为主题的中文文字冒险 + 生存模拟游戏，强调历史真实性与思想深度，通过玩家亲身决策体验"为什么抗日战争能赢"这一根本问题。

**核心价值主张：**
- 不是英雄主义单线叙事，而是"无数普通人汇聚成洪流"的群像视角
- 通过机制设计（而非说教）让玩家自主体验群众路线、军事民主、敌后斗争三大历史逻辑
- 具有教育意义的娱乐内容，适合作为历史课辅助材料

**目标用户：**
- 对中国近代史感兴趣的中文玩家（18-40岁）
- 文字冒险 / Visual Novel 游戏爱好者
- 历史教师 / 爱国主义教育工作者

## 用户旅程

```
1. 打开 index.html（浏览器直接运行，无需安装）
       ↓
2. 进入序章：烽火起（1937年7月，王二柱视角，卢沟桥事变爆发）
       ↓
3. 通过 2-4 个选项驱动叙事，每次选择影响资源与剧情标志
       ↓
4. 章节推进，视角切换（李明·正面战场 / 张华·文化宣传 / 陈老板·经济战线）
       ↓
5. 管理 8 种资源，在资源匮乏与道德选择之间权衡
       ↓
6. 应对日军扫荡、随机事件等紧张局面
       ↓
7. 到达 1945 年 8 月，根据声望值解锁不同结局
       ↓
8. 查看成就、完成度统计，可开始新周目（肉鸽加成）
```

## 核心机制亮点

### 民心值飞轮

```
亲民行动（帮助村民/减租减息）→ 民心↑
  → 情报准确度↑ + 村民自发补给
  → 战斗胜率↑ + 缴获↑
  → 解锁地道战 / 破袭战高级战术
  → 更大规模胜利 → 民心↑↑（正向飞轮）

脱离群众 → 民心↓
  → 情报断裂 + 补给中断
  → 扫荡无法应对 → 失败风险↑
```

### 结局评价维度（商业化版）

计划实现三维评价：
- 群众路线得分
- 军事民主得分
- 敌后斗争得分

综合评级：S（人民英雄）/ A（优秀指挥员）/ B（合格战士）/ C（独行侠）/ D（脱离群众）
