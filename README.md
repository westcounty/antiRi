# 《星火》抗日主题游戏

> 一款以抗日战争为主题的中文文字冒险 + 生存模拟游戏，通过多视角叙事与资源管理机制，带玩家亲身体验"为什么抗日战争能赢"。

## 功能特性

- **多视角叙事**：4 个角色（村民王二柱、国军士兵李明、记者张华、商人陈老板），7 个章节覆盖 1937–1945 年全程
- **资源管理**：食物、弹药、情报、声望、金钱、药品、民心值、群众基础共 8 种资源，相互影响
- **群众路线系统**：民心值决定情报准确度、补给来源和高级战术解锁
- **军事民主系统**："诸葛亮会"战前讨论、战后复盘积累永久战术加成
- **敌后斗争系统**：日军扫荡事件、麻雀战 / 地雷战 / 破袭战游击战术
- **多分支剧情**：每节点 2–4 个选择，影响资源与剧情标志位
- **结局系统**：胜利（完美/好/普通）+ 失败（死亡/饿死）+ 特殊结局
- **成就系统**：8 种成就，满足特定条件自动解锁
- **随机事件**：章节推进时概率触发，增加不确定性
- **肉鸽支持**：多周目里程碑解锁资源/战术加成
- **完成度统计**：追踪所有访问节点，显示探索进度
- **localStorage 存档**：多存档槽位，支持版本迁移
- **PC / 移动端适配**：响应式布局，支持触屏操作

## 技术栈

| 技术 | 版本 / 说明 |
|------|-----------|
| HTML5 | 游戏 DOM 骨架与入口 |
| CSS3 | 响应式布局，PC / 移动端适配 |
| JavaScript（原生 ES6+） | 游戏逻辑，无框架依赖 |
| localStorage | 存档持久化 |

无任何第三方库或构建工具依赖。

## 快速开始

### 环境要求

- 任意现代浏览器（Chrome / Firefox / Safari / Edge）
- 无需 Node.js、无需服务器、无需安装

### 运行方式

```bash
# 方式一：直接在文件管理器中双击
index.html

# 方式二：用 VS Code Live Server 或 Python 简易服务器（避免部分浏览器的本地文件限制）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

## 游戏玩法简介

1. 在浏览器中打开 `index.html`
2. 从序章开始，扮演河北农民**王二柱**体验 1937 年七七事变
3. 每个剧情节点提供 2–4 个选择，影响 8 种资源与剧情走向
4. 随章节推进切换视角：王二柱（敌后）→ 李明（正面）→ 张华（文化）→ 王二柱（经济）
5. 到达 1945 年 8 月，根据声望值解锁不同结局
6. 查看成就与完成度，开始新周目

## 注意事项

- 游戏内容基于历史事实，旨在传播正确的历史观和价值观
- 无痕浏览模式下 `localStorage` 不持久化，存档将丢失
- 多个 `script_*.js` 为迭代版本，主入口为 `script.js`，其余按需加载
